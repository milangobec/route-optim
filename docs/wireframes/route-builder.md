# Wireframe: Route Builder (Hour 9)

Select stops from a list to add to a named route. Ordering here just determines the naive input order.

```
+---------------------------------------------+
|  New Route                                   |
+---------------------------------------------+
|  Route name: [ Tuesday Deliveries_______ ]    |
|                                               |
|  Available stops         Added (input ord.)  |
|  [ ] Stop A                1. Depot          |
|  [ ] Stop B          ->    2. Stop C         |
|  [ ] Stop C                 3. Stop A         |
|  [ ] Stop D                 4. Stop B         |
|  [ ] Stop E                                   |
|                                               |
|  [ Save Route ]                              |
+---------------------------------------------+
```
