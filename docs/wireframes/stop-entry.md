# Wireframe: Stop Entry (Hour 9)

Click anywhere on the Leaflet map to drop a pin and name it. No geocoding API needed, no manual lat/lng typing required, though a manual-entry fallback is easy to add.

```
+---------------------------------------------+
|  Route Optimizer > Add Stop                  |
+---------------------------------------------+
|                                               |
|   +-------------------------------------+   |
|   |                                     |   |
|   |      [ Leaflet map ]               |   |
|   |      click to drop a pin           |   |
|   |                                     |   |
|   +-------------------------------------+   |
|                                               |
|   Selected location: 41.8781, -87.6298       |
|   Stop name: [_________________________]     |
|                                               |
|   [ Add Stop ]                               |
+---------------------------------------------+
```
