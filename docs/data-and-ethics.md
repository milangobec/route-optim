# Data and Ethics Note (Hour 12 preparation)

Use synthetic stops, random coordinates within a plausible bounding box (e.g. one city), not real personal addresses. Keep a couple of hand-built controlled sets with a known optimal tour (e.g. stops arranged in a perfect square or triangle, where the obviously-best order can be verified by inspection), these are the SC3/SC4 correctness anchors, alongside the worked example in docs/algorithms/worked-example.md.
